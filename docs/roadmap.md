# Video Compose 项目画像与路线图

## 项目概述
Video Compose 是面向人和多个 Agent 的开源视频作品编排协议与轻量协作工作台。不同 Agent 可读取同一项目、变更分镜并向项目交付媒体资产，而不需要共享模型或生成运行时。系统只定义作品结构、素材引用、修订及权限。

目标数据流（设计，尚未实现）：Web / Agent -> REST / MCP -> 统一领域操作 -> D1（项目、修订、索引）和 R2（不可变资产）。

## 项目画像（目标状态）
一份可移植、机器可验证的视频作品定义，支持多分镜、时间线、图片/视频/音频引用、候选素材、稳定身份和可追溯修改。角色与道具不仅是图片文件，也有项目级可复用的身份、定义、版本、外观/状态变体及多张权威参考图；分镜固定引用确定的主体设定版本。人与 Agent 拥有相同的读写协议接口，提供轻量网格、清单、拓扑和上下文 Agent 侧栏。

冲突时价值优先级：数据正确性与可恢复性 > 协议兼容性与可移植性 > 权限隔离 > 协作体验 > UI 外观。

## 当前能力清单
- **开源仓库与文档**：GitHub Public 仓库已创建；本文件、README、AGENTS 和架构约定说明目标状态，不代表产品能力已实现。
- **协议、API、MCP、资产、界面及协作能力**：规划/未实现；尚无产品 E2E 实测结果。

## 非目标（铁律）
- 不内置视频或图像生成模型，不提供模型节点工作流/ComfyUI 克隆。
- 不承担 FFmpeg 合成、渲染执行或模型任务调度。
- 不实现发布到 YouTube、社交平台或内容分发功能。
- 不把供应商密钥、临时媒体 URL、模型推理参数变成强制协议字段。
- 不把聊天日志当作项目编排权威数据，不允许静默最后写入覆盖。

## 方向与意图
1. **项目与编排管理**：一个项目容纳多条独立编排，共享资产。
2. **声明式编排协议**：稳定镜头 ID、时间线、参考图/参考视频、视频/音频候选、Prompt 与可扩展元数据。
3. **不可变资产管理**：媒体导入、校验、关联、复用和来源追踪。
4. **角色/道具设定与参考图管理**：对角色、道具建立项目级结构化设定、多视角参考图集、外观或状态变体与明确的设定修订；镜头可复用确定的设定版本，设定变更不静默影响旧编排。
5. **多 Agent 协作修订**：带身份的结构化修改、冲突检测、可回退历史、审阅提案。
6. **统一 HTTP/MCP 接入**：UI 与任何授权 Agent 观察并修改相同状态。
7. **轻量可视化工作台**：网格、清单、依赖拓扑、媒体预览、上下文 Agent 侧栏。
8. **开放交换与兼容性**：导入导出可验证的 JSON/YAML 编排定义并保持版本兼容。

## 完成的样子
- 两个独立 Agent 和一名人类能在同一项目无数据丢失地协作，冲突可解释、可修复。
- 任意历史修订可重建；每个媒体引用要么解析为受权访问的不可变资产，要么明确报错。
- 角色与道具的权威参考图集被新版本替换后，历史镜头仍绑定原设定版本；可明确比较、选择是否更新引用。
- 编排 JSON/YAML 往返不改变作品语义；UI 三视图使用同一领域模型。
- 产品可脱离具体生成供应商运行。

1. 每个一级功能至少有一条 Happy Path 的 E2E 验证。
2. 每个高风险功能至少覆盖一条失败路径。
3. 每个涉及权限的功能至少验证两种角色（有权与无权）。
4. 每个会修改系统状态的操作至少验证一次失败后的恢复或回滚。
5. 每次新增一级业务功能，必须同步新增对应的 E2E 并登记进本矩阵。

### 已识别缺口和最低期望
- **项目与编排**：有权用户能创建项目和编排；无权写入被拒；失败不留半成品。
- **协议**：合法样例通过；缺失 ID、循环依赖、引用无效均给出稳定机器错误；校验不修改输入。
- **资产**：上传校验后可跨镜头复用；哈希不匹配或越权拒绝；失败上传不登记可见资产。
- **设定与参考图**：有权者创建角色/道具设定、登记并批准多张参考图、绑定两个分镜至同一设定修订；生成新的角色/道具版本不改变旧镜头所引用版本；不存在、越权、冲突或资源损坏时操作失败且原状态不变。
- **协作**：两个 Agent 的不相交 Patch 可安全合并，同一字段冲突可机读，任何历史修订可恢复。
- **HTTP/MCP**：同一操作经 REST 与 MCP 得到一致结果；匿名/越权操作拒绝；失败可安全重试。
- **工作台**：分镜在三视图显示一致，编辑与撤销不丢失，越权操作不能通过 UI 绕过 API。
- **交换**：JSON/YAML 导出重新导入语义不变；损坏格式拒绝，原数据不变。

真实 E2E/集成证据出现前，所有缺口均不得标记完成。
